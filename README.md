# 🛡️ Terminal FaceControl System

Полноценное консольное приложение на Python для учета посетителей и проверки по критериям фейсконтроля. Программа работает с реальной базой данных SQLite, имеет интерактивный цветной интерфейс и надежную защиту от ошибок ввода.

## ✨ Особенности (Features)

* **Надежная логика проверок:** Система автоматически оценивает посетителей по возрасту (16+) или по комбинации возраста и роста (12+ лет и 160+ см).
* **База данных под капотом:** Использование `sqlite3` для сохранения истории визитов. Данные не пропадают после закрытия программы.
* **Автоматический учет времени:** Программа сама фиксирует точное время прохождения фейсконтроля с помощью модуля `datetime`.
* **Защита от сбоев (Fail-Fast):** Безопасный ввод данных (`try/except`). Программа не "падает" при вводе букв вместо цифр и блокирует ввод отрицательных значений или пустых имен.
* **Продвинутый UI терминала:**
    * Автоматическая очистка экрана (`os.system('cls')`) для чистого интерфейса.
    * Имитация задержек и загрузки (`time.sleep`) для улучшения UX.
    * Цветной вывод сообщений об ошибках и успешных действиях (с помощью `colorama`).
    * Генерация красивого табличного отчета в конце смены (с помощью `prettytable`).

## 🛠️ Технологии

* **Язык:** Python 3
* **Стандартные библиотеки:** `sqlite3`, `datetime`, `os`, `time`
* **Внешние библиотеки:** `colorama`, `prettytable`
