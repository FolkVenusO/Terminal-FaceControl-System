# 🛡️ FaceControl System & Web Dashboard

Комплексная система управления посетителями клуба. Проект состоит из двух связанных модулей: консольного приложения для работы "на входе" (проверка и запись) и полноценной веб-панели администратора для аналитики и управления базой данных.

## 🏗️ Архитектура проекта

Система разделена на два независимых интерфейса, которые работают с единой базой данных SQLite (`guests.db`):

1. **Terminal App (`Terminal FaceControl System.py`)** — рабочее место охранника. Строгая логика фейсконтроля (возраст, рост, черный список), защита от ошибок ввода и запись пропущенных гостей в базу.
2. **Web Dashboard (`web.py`)** — панель администратора. Чтение базы в реальном времени, статистика, поиск, построение графиков и возможность удаления записей (CRUD-система).

## ✨ Главные возможности

### Консольный модуль (Вход):
* **Система критериев:** Автоматический пропуск по возрасту (16+) или параметрам (12+ лет и 160+ см).
* **Черный список:** Блокировка конкретных имен (например, "Валера").
* **Fail-Fast:** Безопасный ввод данных (`try/except`), предотвращающий падение программы при вводе некорректных значений.
* **Логирование:** Все события (успешный вход, отказы) скрыто записываются в файл `security.log`.

### Веб-модуль (Управление):
* **Live-статистика:** Расчет общего количества гостей, среднего возраста и роста в реальном времени.
* **Умный поиск:** Мгновенная фильтрация таблицы гостей по имени без учета регистра.
* **Интерактивные графики:** Визуализация распределения гостей по возрасту и росту.
* **Безопасное удаление:** Возможность точечно удалять нарушителей из базы по уникальному `ID`.

## 🛠️ Стек технологий

* **Язык:** Python 3
* **База данных:** SQLite3 (встроенная)
* **Веб-фреймворк:** Streamlit
* **Библиотеки:** `colorama` (дизайн терминала), `prettytable` (таблицы в консоли), `datetime` (учет времени).
